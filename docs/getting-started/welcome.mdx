# Welcome

Welcome to the **SCRL Robotics Wiki**, a community-editable knowledge base for combat robotics.

This wiki started as *Beetleweights for Dummies*, a guide originally written by [Leo Ping](https://github.com/lpingpong) as a reference for future members of UTRA Combat, the University of Toronto's combat robotics team. It has grown into a living, community-maintained resource covering everything from your first robot design to advanced weapon-stack engineering.

## How to use this wiki

- **[Getting Started](/getting-started/what-is-a-beetleweight)**: what a beetleweight is, safety, and the rules.
- **[Robot Design](/robot-design/archetypes)**: robot archetypes, ground game, materials, and construction methods.
- **[Drive Systems](/drive-systems/drive-systems)**: drivetrains, wheels, spinning weapon design, and weapon stacks.
- **[Manufacturing](/manufacturing/manufacturing)**: making the parts: laser cutting, CNC, 3D printing.
- **[Electronics](/electronics/electronics-and-wiring)**: batteries, ESCs, control systems, and wiring.
- **[Testing & Safety](/testing-and-safety/testing-and-safety)**: test boxes, weapon locks, LiPo safety, and competition prep.
- **[Appendices](/appendices/casting-wheels)**: advanced topics: casting wheels, bending titanium, threadlockers, and more.

## Contributing

This is a **community wiki**, and anyone can contribute!

The wiki lives in the [scrl-robotics/wiki](https://github.com/scrl-robotics/wiki) repository. The easiest way to contribute is to click the **edit this page** link at the bottom of any page, which opens the file in GitHub where you can propose a change via a pull request.

For larger additions or changes, see the [contributing guide](https://github.com/scrl-robotics/wiki/blob/main/CONTRIBUTING.md).
